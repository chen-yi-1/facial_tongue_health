# 生活建议系统设计文档

## 概述

为面部与舌象健康识别系统增加生活建议功能，将三分类结果（健康/亚健康/不健康）映射为多维度的个性化生活建议。采用规则映射与 AI 生成混合方案（C 方案），同一套结果可展示标准建议和 AI 建议两个版本，支持论文对比分析。

## 架构

### 系统组件

- **规则引擎**：代码中硬编码 3 类 × 5 维度 = 15 条建议文案，查表返回（毫秒级）
- **AI 生成器**：调 DeepSeek API，将分类标签和概率传入 prompt，生成 5 维度的个性化文本
- **异步协调层**：/predict 同步返回规则建议，前端异步调 /advice/ai 获取 AI 建议

### 数据流

```
上传图片 → 模型推理 → 分类结果
                     ↓ 并行
                ┌──────────────────────┐
                │ 规则引擎 (毫秒级)     │
                │ AI 生成器 (1-3s)     │
                └────────┬─────────────┘
                         ↓ 合并
/predict 返回 { label, probabilities, advice: { rule: {5维} } }
/advice/ai 返回 { advice: { ai: {5维} } }
```

## 规则建议文案

### 资料来源

| 来源 | 文件/指南 |
|------|----------|
| 国家卫生健康委 / 中国营养学会 | 《中国居民膳食指南（2022）》 |
| 国家卫健委 / 国家中医药管理局 | 《中国公民中医养生保健素养》 |
| 中华中医药学会 | 《亚健康中医临床指南》（ZYYXH/T2—2006） |
| 国家卫生健康委 | 《心理健康素养十条》 |
| 国家卫生健康委 | 《中国公民健康素养66条（2024年版）》 |
| 世界卫生组织 | 健康四大基石 |

### 健康

| 维度 | 建议内容 |
|------|----------|
| 饮食调理 | 坚持谷类为主的平衡膳食模式，每天摄入12种以上食物。保证蔬菜≥300g/天（深色蔬菜过半）、水果200-350g/天。少盐少油（盐≤5g、油25-30g/天），足量饮水。 |
| 作息建议 | 保持规律作息，保证每晚7-9小时优质睡眠。固定上床和起床时间，睡前1小时减少电子屏幕使用。午休20-30分钟养心经。 |
| 运动指导 | 每周至少150分钟中等强度有氧运动，每周2次以上抗阻力训练。坚持每天6000步主动身体活动。 |
| 中医调理 | 平和体质，保持良好生活习惯。顺应四季养生（春夏养阳、秋冬养阴）。常按足三里、涌泉等保健要穴。 |
| 心理调节 | 保持乐观、开朗、豁达的生活态度。适量运动有益情绪健康，压力时积极寻求人际支持。 |

### 亚健康

| 维度 | 建议内容 |
|------|----------|
| 饮食调理 | 均衡营养，增加深色蔬菜和全谷物摄入，选择瘦肉、鱼类、豆制品等优质蛋白。减少高油高盐高糖食物。适量饮水，少量多次。 |
| 作息建议 | 尽量在23点前入睡，保证7-8小时睡眠。避免熬夜，午休20分钟补充精力。睡前避免剧烈运动和电子产品。 |
| 运动指导 | 每周3-5次中等强度有氧运动，每次30分钟以上。推荐八段锦、太极拳等传统养生功法。避免过度疲劳。 |
| 中医调理 | 根据体质辨证调养（气虚质补气、痰湿质化湿等）。常按足三里（健脾胃）、涌泉穴（助睡眠）。可配合药膳调理。 |
| 心理调节 | 学会科学减压，调整消极想法，把目标设定在能力范围内。每天10分钟深呼吸或冥想。避免吸烟、酗酒、沉迷游戏。 |

### 不健康

| 维度 | 建议内容 |
|------|----------|
| 饮食调理 | 建议咨询专业医师或营养师制定个性化饮食方案。选择易消化、富含营养的食物，少食多餐，避免生冷、油腻及刺激性食物。 |
| 作息建议 | 保证充足休息，每天睡眠8小时以上。避免任何形式的熬夜。睡眠质量持续低下时及时就医。 |
| 运动指导 | 在医师指导下进行适量温和活动（如散步），从每天15分钟开始循序渐进。避免中高强度运动。 |
| 中医调理 | 及时就医，在专业中医师指导下系统治疗。遵循"既病防变"原则，可配合针灸、推拿、中药等综合手段。 |
| 心理调节 | 正视健康问题，积极就医。主动向家人朋友倾诉寻求帮助。必要时可拨打12320卫生热线或寻求专业心理咨询。 |

## 前端变更

### 页面布局

结果展示区下方新增「生活建议」模块，包含：

- **Tab 切换栏**：「标准建议」|「AI 建议」
- **建议卡片网格**：5 个维度以 2×3 网格排列（前 4 个 2×2，最后一个跨列）
- 每个卡片含：维度图标 + 标题 + 建议文本

### 交互流程

1. 提交分析 → 显示结果 + 标准建议（规则版，立即展示）
2. 自动触发 `/advice/ai` 异步请求 → 返回后激活 AI 建议 Tab
3. 用户点击「AI 建议」→ 切到 AI 版本
4. 用户点击「标准建议」→ 切回规则版本
5. AI 建议加载中时 Tab 显示加载状态

## 论文支持

### 可展示的工作量

1. **规则系统设计**：自主查阅和整理了多份国家权威健康指南，结构化输出 15 条专业化建议
2. **混合架构设计**：设计了规则 + AI 双轨并行的异步架构，前端 Tab 切换对比
3. **对比实验素材**：同一结果的标准建议 vs AI 建议，可在论文中展示对比分析

### 论文中可用的图表

- 系统架构图（数据流）
- 建议展示效果截图（标准版 / AI 版）
- 规则建议内容表格（3×5 = 15 条一览）
- AI 生成建议与规则建议的风格对比

## 实施计划

### 阶段一：规则引擎（后端）

1. 在 `app/advice_rules.py` 中定义 15 条建议数据结构和查询函数
2. 修改 `app/app.py` 的 `/predict` 接口，返回 `advice.rule` 字段
3. 新增 `POST /advice/ai` 接口，调 DeepSeek API 生成 AI 建议

### 阶段二：前端展示

4. 在 `index.html` 结果区下方新增生活建议模块 DOM 结构
5. 在 `style.css` 中新增建议卡片、Tab 切换、加载状态样式
6. 在 `main.js` 中新增异步请求、Tab 切换逻辑

### 阶段三：AI 集成

7. 配置 DeepSeek API Key（环境变量）
8. 编写 prompt 模板，将分类标签和概率转为结构化建议
9. 错误处理：AI 建议失败时不影响规则建议展示

### 阶段四：论文材料

10. 按需微调建议文案
11. 整理论文可用的对比截图和表格数据
